# Genesis v2 Dashboard — 部署提示词 / Deploy Prompt

> 以下提示词用于在 Cursor 中指导部署仅包含前端仪表盘的版本，不部署 LLM 后端，不暴露 API key。

---

## 中文版提示词

```
请帮我将 genesis_v2 的 Streamlit 仪表盘部署为独立前端服务，要求如下：

1. 只启动仪表盘，不启动任何 LLM 后端实验进程
2. 仪表盘中所有岛屿默认使用 Mock 模式（免费，无需 API key）
3. 移除或注释掉所有 API key 输入区域的默认值，确保部署版本不包含任何真实 API key
4. Monitor 标签页使用内置的演示数据（_generate_demo_status），不依赖真实实验数据
5. 保留 Config 标签页的全部配置功能，用户可以自行配置参数
6. Run 标签页的 Start 按钮：如果用户选择 Mock 模式则正常启动；如果选择非 Mock 后端则弹窗提示需要自行配置 API key
7. 确保 data/api_keys.env 文件不被提交到仓库（已在 .gitignore 中）
8. 启动命令：streamlit run genesis_v2/scripts/dashboard.py --server.port 8501 --server.headless true
9. 如果部署到公网服务器，需要在 .streamlit/config.toml 中设置 server.address = "0.0.0.0"
10. requirements: Python 3.11+, streamlit>=1.57.0, numpy, pandas, pyyaml, httpx

部署步骤：
- cd genesis_v2
- pip install -e ".[dev]"  或  uv sync --extra dev
- streamlit run genesis_v2/scripts/dashboard.py --server.port 8501 --server.headless true

注意事项：
- data/ 目录在 .gitignore 中，不会被提交
- API key 存储在 data/api_keys.env，部署时该文件为空，用户需自行配置
- Mock 模式完全免费，不需要任何外部 API
- 演示数据由 _generate_demo_status() 生成，使用 random.Random(42) 确保确定性
```

## English Version Prompt

```
Please deploy the genesis_v2 Streamlit dashboard as a standalone frontend service with these requirements:

1. Only start the dashboard — do NOT start any LLM backend experiment process
2. All islands default to Mock mode (free, no API key needed)
3. Remove or clear all default API key values — the deployed version must NOT contain any real API keys
4. The Monitor tab uses built-in demo data (_generate_demo_status) — no dependency on real experiment data
5. Keep the Config tab fully functional — users can configure their own parameters
6. Start button behavior: Mock mode starts normally; non-Mock backends show a dialog prompting the user to configure their own API key
7. Ensure data/api_keys.env is not committed (already in .gitignore)
8. Start command: streamlit run genesis_v2/scripts/dashboard.py --server.port 8501 --server.headless true
9. For public server deployment, set server.address = "0.0.0.0" in .streamlit/config.toml
10. Requirements: Python 3.11+, streamlit>=1.57.0, numpy, pandas, pyyaml, httpx

Deploy steps:
- cd genesis_v2
- pip install -e ".[dev]"  or  uv sync --extra dev
- streamlit run genesis_v2/scripts/dashboard.py --server.port 8501 --server.headless true

Notes:
- The data/ directory is in .gitignore and will not be committed
- API keys are stored in data/api_keys.env, which is empty on deploy — users configure their own
- Mock mode is completely free, no external API needed
- Demo data is generated by _generate_demo_status() using random.Random(42) for determinism
```

## Cursor Rules 版本（可直接放入 .cursorrules）

```markdown
# Genesis v2 Dashboard Deployment Rules

## Environment
- This is a Streamlit dashboard for the Genesis v2 AGI evolution platform
- Deploy as frontend-only: NO LLM backend processes
- All islands MUST default to Mock mode

## API Keys
- NEVER hardcode or commit API keys
- API keys are stored in data/api_keys.env (gitignored)
- On fresh deploy, data/api_keys.env does NOT exist — this is expected
- The Config tab shows API key input fields — users fill in their own keys
- Mock mode works without any API key

## Data
- Demo data is generated by _generate_demo_status() when no real experiment data exists
- The Monitor tab auto-detects: real data if experiment ran, demo data otherwise
- data/ directory is fully gitignored

## Start Command
streamlit run genesis_v2/scripts/dashboard.py --server.port 8501 --server.headless true

## Security Checklist
- [ ] No API keys in code or config files
- [ ] data/api_keys.env not committed
- [ ] .env files not committed
- [ ] Mock mode is the default for all islands
- [ ] GitHub stars API uses unauthenticated requests (rate-limited, has fallback)
```
