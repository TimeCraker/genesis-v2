# Project Genesis v2：从单细胞到文明

> 设计理念与仿生学白话版。不讲公式，只讲"我们到底在造一个什么样的东西，以及为什么这样做"。

v1 的故事是这样的：我们造了一个单细胞生物，给它一个宇宙、一个饥饿的身体，看它能不能活着。答案是——能活，但只是个会预测的应激生物，就像草履虫碰到酸会缩一下。**它永远不会发明语言，更不会思考"我是谁"。**

v2 要问一个更野心的问题：**如果我们给单细胞生物加上社交、加上自我改造的能力、加上多个不同的宇宙——它会不会自己发展出文明？**

---

## 一、它的多元宇宙：不是一个物理法则，而是一整个"法则族"

- **v1 的问题**：只用一个 LLM 当物理法则。Agent 很快就"背题库"了——它不是理解了宇宙，而是记住了这一个宇宙的出题规律。换个宇宙（换个 LLM），它就傻了。
- **v2 的做法**：我们造了**四片大陆**，每片大陆的物理法则由不同的大模型驱动（DeepSeek、Gemini、MiMo……）。

  - **形象类比**：想象一个孩子，出生在中国，5 岁搬到法国，10 岁搬到巴西。他不是学会了中文、法语、葡萄牙语——他被迫学会了**"语言本身是什么"**。他理解了沟通的底层逻辑，所以到任何一个国家都能快速适应。
  - 我们的 Agent 也一样：定期在不同 LLM 大陆之间迁移。能活下来的，不是背了最多题库的，而是**理解了"宇宙为什么这样运作"的**。

## 二、它的社交：从孤独的个体到嘈嘈杂杂的文明

- **v1 的问题**：200 个 Agent 住在同一个世界里，但彼此完全不认识。它们的行为被取了个平均值，仅此而已。就像 200 个人各自关在单间里——永远不可能发展出语言、贸易、文化。
- **v2 的做法**：Agent 们被摆在一个**二维网格**上，每个 Agent 能和附近的邻居"说话"。

  - **形象类比**：想象一个村庄。你家隔壁的邻居说的话你能听到，但隔了三条街的就听不到了。如果你想和远处的人交换信息，你需要**想办法让消息一站一站地传过去**——这就是"通信协议"的起源。
  - 我们不教 Agent 怎么说话。我们只是说：**你有一个嘴巴（128 维消息通道），一对耳朵（收件箱），和一群邻居。怎么用，你自己看着办。**
  - 配合社交压力（资源共享、集体任务、互惠奖励），Agent 为了活命，**被迫**开始尝试传递有意义的信号。语言，就是在这种"不沟通就会饿死"的压力下涌现的。

## 三、它的大脑升级：从标量细胞到向量神经元

- **v1 的问题**：每个"神经元"只能算一个数字（标量）。128 个神经元才能表示一句话的意思。这就像一个人的大脑里只有一根神经纤维——再怎么连也连不出复杂的思维。
- **v2 的做法**：每个神经元现在能处理一个**64 维向量**。连接的"突触"不再是单个数字的权重，而是一个**小矩阵**（64×64）。

  - **形象类比**：v1 的神经元像一个单色灯泡（只能亮或灭），v2 的神经元像一块 LED 屏幕（能显示复杂的彩色图案）。一个 LED 屏幕能表达的信息量，远超一百个灯泡。
  - 新增的变异类型也更丰富了：注意力机制（Q/K/V 计算原语）、模块注入（一次长出一小片功能组织）、维度拆分合并（把一个大屏幕拆成几个小屏幕，或反过来）。这些不是"人类认知模块"——它们是更底层的数学原语，就像细胞分裂和细胞融合。

## 四、它的进化升级：从无性繁殖到有性繁殖

- **v1 的问题**：只有无性繁殖——精英个体克隆自己，然后随机变异。这就像细菌分裂，效率低，容易陷入局部最优。
- **v2 的做法**：加入**交叉重组（Crossover）**——两个精英 Agent 的基因图谱被切开、缝合。

  - **形象类比**：v1 是细菌（克隆），v2 是有性生殖的动物。有性生殖的本质是——把父母各自的优势基因组合起来，赌一把下一代会不会"青出于蓝"。
  - 加上**跨代记忆**：精英 Agent 死后，它的"人生经验摘要"（哪些行为模式让它活得最久）被保存下来，50% 概率传递给后代。这不是把记忆硬编码进 DNA，而更像是一种"家训"——"我这辈子发现这样做最有效，你试试看"。

## 五、它的手术刀：自我修改——从"被选择"到"自我选择"

- **这是 v2 最大胆的设计。**
- **形象类比**：自然界的进化是盲目的——随机变异，适者生存。这需要百万年。但人类不同：人类能**有意识地改变自己**。发明眼镜是因为看不清，发明抗生素是因为会生病。人类不只是被自然选择——人类在**选择自己**。
- **我们的设计**：Agent 的输出向量最后 16 维，被解释为"给自己做手术的指令"。

  - 想象你的大脑突然长出了一个想法："我的视觉皮层反应太慢了，如果把这一块神经重新连一下会更好"。然后你就真的拿起手术刀，给自己做了个微创手术。
  - 当然，给自己做手术极其危险——70% 的概率会搞砸（越改越差甚至直接死亡）。只有真正**理解自己哪里有问题**的 Agent，才能活下来。
  - 这需要 Agent 发展出**自我模型**（理解自己的结构和行为模式）和**因果推理**（预测"如果我这样改，会怎样"）。这两个能力，正是 AGI 的核心特征。

## 六、它的探索欲：不只背题库，还要发现新大陆

- **v1 的问题**：选择压力只有"预测准"和"压缩好"。Agent 永远在模仿 LLM 说了什么——永远是人类知识的影子，不会超越。
- **v2 的做法**：加入**探索奖励**——当 Agent 做出了 LLM 认为"不可能"的行为，但 Agent 自己完全能预测这个行为时，获得额外能量。

  - **形象类比**：一个学生把教科书背得滚瓜烂熟，考试满分——这叫"拟合"。另一个学生在考试中写出了一种教科书上没有的解法，但逻辑自洽、结果正确——这叫"超越"。
  - 探索奖励鼓励的是后者。我们希望看到的不是"Agent 把 LLM 的话复述得越来越好"，而是"Agent 开始做出 LLM 没有预料到的、但有意义的行为"。

  - **阶段转变是自然的**：初期预测奖励高，Agent 专注学习。当人类知识学得差不多了（预测奖励边际递减），探索奖励的相对价值就上升了——Agent 自然而然地从"学生"变成了"探险家"。

## 七、它的翻译器：从向量脑波到人类语言

- **最终目标**：人能和 Agent 对话。
- **怎么做**：Agent 的大脑在向量空间里运转（64 维向量 = 它的"思维语言"）。我们准备了一本"宇宙物理字典"（冻结的投影矩阵 P），能把向量翻译成 LLM 的 token（人类语言的最小单位），反过来也行。

  - **形象类比**：你的大脑里并没有"中文"或"英文"——你的思维是一团电化学信号。是你的"语言中枢"把这些信号翻译成了可发音的文字。投影矩阵 P 就是 Agent 的"语言中枢"——它把 Agent 的纯数学思维"播放"成人类能理解的语言。
  - **关键**：这不违反"无硬编码"红线。投影矩阵是宇宙常数（像光速一样），不是 Agent 的一部分。Agent 的"想法"是它自己演化出来的，P 只是把想法"翻译"出来。

## 八、它的安全网：预算即代谢，降级即气候变化

- **实际问题**：调用大模型 API 要花钱。400 个 Agent 每 tick 都调 API，一天下来可能花掉几百块。
- **我们的设计**：**API 调用的成本直接从 Agent 能量里扣。** 这意味着——低效的 Agent（花很多 token 但预测不准）会快速饿死。这创造了"用最少的话做最准确的预测"的选择压力。

  - 预算有硬上限（$50）。花完了怎么办？系统自动"降温"——从云端大模型切换到免费的数学模拟环境。Agent 不知道"气候变化"发生了，它只是感觉"宇宙突然变得简单了"。
  - 这就像地球的冰河期——环境剧变，只有适应力最强的物种能活下来。

# 和 v1 PRD 的对照速览

| 故事里的概念 | v1 的做法 | v2 的升级 |
|---|---|---|
| 宇宙 | 一个 LLM | 多个 LLM（DeepSeek/Gemini/MiMo + Mock） |
| 神经元 | 标量（1 个数字） | 向量（64 维），突触是矩阵 |
| 大脑结构 | 7 种变异 | 12 种变异（+注意力/模块/拆分/合并/通信边） |
| 繁殖 | 无性（克隆+变异） | + 有性（Crossover 交叉重组） |
| 传承 | 无（记忆清零） | GenerationalMemory（经验摘要跨代传递） |
| 社交 | 无（完全独立） | 网格邻居通信 + 声誉系统 + 集体任务 |
| 自主性 | 无（纯被选择） | 自我修改通道（16 维输出 → 变异指令） |
| 探索 | 无 | 探索奖励（LLM 惊讶 − 自我惊讶） |
| 说话 | 无 | 冻结投影矩阵 P（向量 ↔ token 翻译） |
| 花钱 | 无（本地运行） | 预算管理 + 自动降级 |

# 一句话总结

> v1 问的是：**"智能会不会自己长出来？"**
>
> v2 问的是：**"如果给它社交、多元宇宙、自我改造的能力和探索的动力——文明会不会自己长出来？"**

> 它不声称一定能造出 AGI。但它设计了一条从"单细胞"到"文明"的完整路径，并且每一个阶段都是可检验、可证伪的。
>
> 最坏的情况：我们得到了一批在多个 LLM 之间快速适应的、能互相通信的、能自我修改的数字生物——即使它们还没有"理解"任何东西，这些行为本身就已是值得研究的演化现象。
>
> 最好的情况：我们看到语言在社交压力中涌现，看到自我意识在自我修改中萌芽，看到 Agent 开始做出人类没有预料到的行为。
>
> 无论哪种结果，都是诚实的科学。
